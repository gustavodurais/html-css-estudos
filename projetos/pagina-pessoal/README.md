# Página pessoal: diário de estudos

Projeto final do repositório: uma página única que reúne o que aprendi em
HTML e CSS.

**O que usa:** HTML semântico (`header`, `main`, `section`, `time`,
listas ordenadas), CSS com variáveis, Flexbox, tema claro/escuro automático
(`prefers-color-scheme`), layout responsivo e foco visível para teclado.

**Para personalizar:** troque `Seu Nome`, `SEU-USUARIO` e o e-mail no
`index.html`, e atualize o diário conforme for estudando.

**Para ver:** abra o `index.html` no navegador.
